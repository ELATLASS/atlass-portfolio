# Atlass Portfolio

> Atlass Corp — Automated portfolio with live data, case studies, and web publishing

## Overview

This portfolio is automatically updated by Hermes Agent cron jobs that pull fresh data from APIs, generate executive summaries, and deploy to GitHub Pages.

## Structure

- `index.html` — Main portfolio page (auto-deployed to GitHub Pages)
- `data/` — JSON data files (updated by cron)
- `case-studies/` — Generated case study reports
- `metrics/` — Key metric dashboards
- `cron/` — Cron job scripts for automated updates

## Getting Started

```bash
git clone https://github.com/ELATLASS/atlass-portfolio.git
cd atlass-portfolio
```
